casino simulation using pure numpy

run by downloading and running main.py

players are of 3 types conservative, normie and risky, each betting more of their current balance than the previous one

player status kept track of using a numpy arrays, filtered out each round

at the end final report displayed which shows general stats  as well as number of survivors by play style

three types of games available - coin toss, slots and roullete, each chosen randomly for each round. 60 rounds total.
